## [1.1.0] - 2026-09-01

### Changed
- Mini app теперь не масштабируется щипком/двойным тапом (портило вид формы добавления
  траты на iOS — поле при фокусе само зумило страницу).
- Поля ввода получили визуальный контраст с фоном (заливка + более заметная граница,
  подсветка при фокусе) вместо слияния с фоном шторки.
- Категории трат получили иконки-эмодзи для быстрого визуального различения — в списке
  трат (плейсхолдер и бейдж), в статистике (список и легенда диаграммы), в выпадающих
  списках выбора категории. Только на фронтенде, сами категории остались строками.
- Форма добавления траты стала компактнее и рассчитана помещаться на экране без прокрутки:
  название и фото чека — в одну строку, «кто оплатил» и сумма — в одну строку, категория
  и дата — в одну строку, переключатель способа деления переведён на единый «трек» с
  плавающей активной пилюлей.
- В списке участников (равное и ручное деление траты) теперь показываются настоящие
  аватарки из профиля Telegram — кружок с первой буквой имени, если фото недоступно.

### Added
- Синхронизация фото профиля участника из Telegram (один раз, при первом появлении
  участника — по сообщению в группе, входу в чат или первому открытию mini app) для
  отображения аватарки. Требует новую миграцию БД (`Member.avatar_path`).

## [1.0.1] - 2026-09-01

### Fixed
- Кнопка «Открыть учёт трат» не приходила в групповых чатах: Telegram разрешает
  `web_app`-кнопки только в личных чатах с ботом и отклонял всё сообщение целиком.
  В группах кнопка теперь использует прямую ссылку (`t.me/<бот>?startapp=...`), которую
  Telegram позволяет открывать откуда угодно, включая группы; mini app считывает id чата
  из `start_param`, если его нет в query-параметре.

## [1.0.0] - 2026-09-01

### Added
- Telegram-бот + mini app для учёта семейных трат: название, сумма, фото чека, дата,
  выбор участников (поровну или вручную фиксированной суммой на каждого).
- Автоматическое отслеживание участников чата (Telegram Bot API не отдаёт список участников
  напрямую) — по сообщениям в группе, событиям входа/выхода и первому открытию mini app.
- Баланс участников и упрощённый список «кто кому должен» + ручное погашение долга (settle up).
- Категории трат и статистика по месяцам с диаграммой.
- Повторяющиеся траты (аренда, подписки) с автогенерацией по расписанию.
- Уведомления в чат о новых тратах, удалении, погашении долга и сгенерированных повторах.
- Экспорт месяца в Excel (траты + баланс).
- Docker-развёртывание (docker-compose), CI/CD через GitHub Actions на релизные теги
  (сборка образа → ghcr.io → деплой по SSH).
- Миграции схемы БД на Alembic.
- Автотесты (pytest) на бизнес-логику: сплиты, баланс, повторяющиеся траты, аутентификация.

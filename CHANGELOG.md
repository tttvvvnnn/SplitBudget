## [Unreleased]

### Added
- Поиск и фильтры в списке трат: по названию, категории и участнику (кто платил) —
  сворачиваемая панель над списком, работает мгновенно по уже загруженным тратам месяца,
  сумма сверху пересчитывается под применённый фильтр.
- Список трат сгруппирован по дням — между тратами разных дат вставлен заголовок
  («Сегодня», «Вчера» или день недели и число).
- Вверху вкладки «Траты» появилась компактная сводка личного баланса («Вам должны …» /
  «Вы должны …» / «Все в расчёте 🎉») — тап по ней переключает на вкладку «Баланс» с полной
  картиной. Сама вкладка «Баланс» никуда не делась.
- В правом верхнем углу шапки — версия и метка времени сборки (например `dev · 2026-09-04
  16:20 UTC`). Метка вычисляется прямо во время `docker build` и обновляется только тогда,
  когда в образ реально попал новый код — удобно на стенде, чтобы после `docker compose ...
  --build` на глаз видеть, старая сейчас открыта версия интерфейса или уже новая. Источник —
  `/healthz`, который отдаётся без кеширования.

### Changed
- Аватарки участников (заведённые для формы добавления траты) теперь используются везде,
  где раньше было просто имя текстом: в списке трат («кто оплатил») и на вкладке «Баланс»
  (долги, баланс участников, последние платежи).
- Mini app стал заметно более «нативным» для Telegram: подтверждения удаления и кнопка
  сохранения/добавления теперь используют системные `showConfirm`/`MainButton` вместо
  самодельных, добавлен тактильный отклик (haptic feedback) на выбор участников, способ
  деления, переключение вкладок и успех/ошибку действия, кнопка «назад» Telegram закрывает
  открытую форму так же, как тап по фону.
- Исправлен горизонтальный скролл в форме добавления/редактирования траты: строка
  «название + фото чека» не сжималась и вылезала за пределы шторки на узких экранах;
  отдельно поле «Дата» вынесено из пары с «Категорией» в свою строку — нативный виджет
  выбора даты в некоторых мобильных браузерах отказывался сжиматься до половины ширины.
- Карточки трат в списке получили тонкую границу — в некоторых темах Telegram
  secondary_bg_color почти не отличался от фона, и карточки визуально сливались со страницей.
- Chart.js в статистике теперь лежит в самом проекте, а не грузится с cdnjs.cloudflare.com —
  этот CDN недоступен на части сетей в России, из-за чего график молча не строился.
- Бейдж категории и подсветка поля при фокусе теперь берут цвет из реальной темы Telegram
  (`--link`), а не из захардкоженного синего — в цветных темах (Настройки → Оформление,
  не только тёмная/светлая) эти элементы раньше оставались синими вместо цвета темы.
- Поле «Кто оплатил» обрезает длинное имя многоточием вместо резкого обрыва без него.
- Поле «Дата» всё ещё вылезало за край шторки даже в своей полноширинной строке. Первая
  попытка (скрыть нативные кнопки date-инпута) не помогла — на iOS Safari/WKWebView эти
  псевдоэлементы вообще не рисуются, это Chromium-специфика. Настоящая причина — нативный
  UI-аппиранс `<input type=date>` на iOS может игнорировать `width` целиком; добавили
  `-webkit-appearance: none` (стандартный фикс именно для этого) плюс `width`/`max-width`
  с `!important` как страховку.
- Строка «категория · кто оплатил» под названием траты при длинном @username (не коротком
  имени) переносилась некрасиво: точка-разделитель повисала в конце первой строки, а
  аватар с именем целиком уезжали на вторую — выглядело как будто элементы наезжают друг на
  друга. Теперь это гибкий ряд с одинаковыми отступами: если не помещается — переносится
  аккуратно, с ровными зазорами в обе стороны, а не текстовым переносом.
- Контраст бейджа категории увеличен (фон 12% → 18% + тонкая рамка того же цвета) — в темах
  с приглушённым акцентным цветом текст и фон почти одного оттенка читались с трудом.

### Removed
- Кнопка «Экспорт в Excel» убрана из mini app (эндпоинт на бэкенде остался нетронутым).

## [1.1.0] - 2026-09-01

### Changed
- Mini app теперь не масштабируется щипком/двойным тапом (портило вид формы добавления
  траты на iOS — поле при фокусе само зумило страницу).
- Поля ввода получили визуальный контраст с фоном (заливка + более заметная граница,
  подсветка при фокусе) вместо слияния с фоном шторки.
- Категории трат получили иконки-эмодзи для быстрого визуального различения — в списке
  трат (плейсхолдер и бейдж), в статистике (список и легенда диаграммы), в выпадающих
  списках выбора категории. Только на фронтенде, сами категории остались строками.
- Форма добавления траты стала компактнее и рассчитана помещаться на экране без прокрутки:
  название и фото чека — в одну строку, «кто оплатил» и сумма — в одну строку, категория
  и дата — в одну строку, переключатель способа деления переведён на единый «трек» с
  плавающей активной пилюлей.
- В списке участников (равное и ручное деление траты) теперь показываются настоящие
  аватарки из профиля Telegram — кружок с первой буквой имени, если фото недоступно.

### Added
- Синхронизация фото профиля участника из Telegram (один раз, при первом появлении
  участника — по сообщению в группе, входу в чат или первому открытию mini app) для
  отображения аватарки. Требует новую миграцию БД (`Member.avatar_path`).

## [1.0.1] - 2026-09-01

### Fixed
- Кнопка «Открыть учёт трат» не приходила в групповых чатах: Telegram разрешает
  `web_app`-кнопки только в личных чатах с ботом и отклонял всё сообщение целиком.
  В группах кнопка теперь использует прямую ссылку (`t.me/<бот>?startapp=...`), которую
  Telegram позволяет открывать откуда угодно, включая группы; mini app считывает id чата
  из `start_param`, если его нет в query-параметре.

## [1.0.0] - 2026-09-01

### Added
- Telegram-бот + mini app для учёта семейных трат: название, сумма, фото чека, дата,
  выбор участников (поровну или вручную фиксированной суммой на каждого).
- Автоматическое отслеживание участников чата (Telegram Bot API не отдаёт список участников
  напрямую) — по сообщениям в группе, событиям входа/выхода и первому открытию mini app.
- Баланс участников и упрощённый список «кто кому должен» + ручное погашение долга (settle up).
- Категории трат и статистика по месяцам с диаграммой.
- Повторяющиеся траты (аренда, подписки) с автогенерацией по расписанию.
- Уведомления в чат о новых тратах, удалении, погашении долга и сгенерированных повторах.
- Экспорт месяца в Excel (траты + баланс).
- Docker-развёртывание (docker-compose), CI/CD через GitHub Actions на релизные теги
  (сборка образа → ghcr.io → деплой по SSH).
- Миграции схемы БД на Alembic.
- Автотесты (pytest) на бизнес-логику: сплиты, баланс, повторяющиеся траты, аутентификация.

# Брендинг SplitBudget

Знак «монета пополам»: круг из двух смещённых половинок. Цвета взяты из темы Telegram,
как в мини-приложении.

| Цвет | Где |
|------|-----|
| `#2481CC` | основная половинка, фон аватара, «Split» в логотипе |
| `#6CC1FF` | вторая половинка на светлом фоне |
| `#3E9BE8` / `#8FD0FF` | половинки на тёмном фоне |
| `#1C1C1E` | «Budget» в логотипе |

Шрифт логотипа: Manrope ExtraBold (800), кернинг −2%.

## Файлы

| Файл | Зачем |
|------|-------|
| `logo-mark.svg` | знак для светлого фона |
| `logo-mark-dark.svg` | знак для тёмного фона |
| `logo-mark-white.svg` | белый знак на цветном фоне |
| `app-icon.svg` | круглая иконка, она же `webapp/favicon.svg` |
| `logo-full-light.png`, `logo-full-dark.png` | знак с названием, прозрачный фон |
| `bot-avatar-640.png` | аватар бота: BotFather → `/setuserpic` |
| `bot-description-640x360.png` | картинка описания бота: BotFather → `/mybots` → Edit Bot → Edit Description Picture |

PNG отрисованы из SVG; при правке знака перерисуйте их заново.
